# 手動測試清單

- [ ] 直接開啟首頁或用靜態伺服器，未設定 API 時顯示 Mock 模式並可選身分。
- [ ] 單人晚餐：選條件後有三個推薦與分數，手機畫面沒有水平捲動。
- [ ] 雙人房間：A 建立、分享、B 從 LINE 開連結；A 未完成前 B 看不到 A payload，反向亦然。
- [ ] 兩人各自回答後，在兩支手機都能看到相同晚餐/遊戲結果與歷史。
- [ ] 測試 Web Share API；不支援的瀏覽器可複製邀請文字與網址並貼到 LINE。
- [ ] 修改 Token 或房間代碼後，顯示可理解的錯誤而不是空白畫面。
- [ ] 將 expires_at 改為過去或等待 24 小時，確認房間顯示過期。
- [ ] 同一身分重複送出，確認顯示「你已經回答過囉」。
- [ ] 兩支手機同時送出最後答案，確認 Apps Script 只建立一筆結果（LockService）。
- [ ] 設定 `/exec` 後，設定頁 healthCheck 成功，Rooms/Answers/Results/History 有資料。
- [ ] iPhone Safari：安全區、按鈕高度、分享與複製可操作。
- [ ] Android Chrome：深色模式、返回頁面立即更新與 8 秒輪詢可操作。
- [ ] 開啟減少動態效果偏好，等待與結果動畫不造成困擾。
